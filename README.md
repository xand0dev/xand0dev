## FITGYM / built beyond the demo

> **Real product · Private codebase · Controlled pilot preparation**

FITGYM is a multi-tenant operating platform for fitness clubs—not a dashboard assembled for a portfolio. I co-founded it and lead its product and technical direction while working across the Django/DRF backend, React operations panel, React Native member app, integrations, infrastructure, and releases.

The difficult part is not CRUD. Each club must remain isolated while bookings, capacity, memberships, QR access, payments, and staff actions obey server-side rules under real operational pressure.

The release path is part of the product: CI gates, containerized deployment, managed PostgreSQL, web and mobile delivery, backup/restore verification, post-deploy smoke checks, and rollback planning.
